#### 1.4.0

- **Fix:** named groups now work with *Multi-Match* (previously the whole match was returned).
- **Fix:** without *Multi-Match* the first match wins (previously the last matching line did).
- **Fix:** every input item is processed (previously only the first one).
- Group Name is optional: empty extracts every named group `(?<name>...)`; comma-separated names supported.
- Clear errors for invalid regex or a group name that does not exist (lists the available ones).
- Groups that do not match return `null` (or `[]` with Multi-Match) instead of disappearing.
- New *Options*: Ignore Case (default on), Unicode Mode (default off, `u` was forced before), Dot Matches Newline, Keep Input Fields.
- Whole-text mode no longer implies `s`; `^`/`$` match at line boundaries (flag `m` always on).
- Multi-line inputs for text and expression.
